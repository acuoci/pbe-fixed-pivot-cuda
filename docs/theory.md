# Theory: Population Balance Equations and the Fixed Pivot Method

This document summarises the mathematical formulation underlying the `pbe_cuda` library. Full derivations, convergence analyses, and validation results are reported in the associated publication:

> A. Cuoci, *GPU-Accelerated Fixed-Pivot Population Balance Simulations: Enabling High-Resolution Modeling of Aggregation–Breakage Systems*, [Journal], 2026.

---

## 1. Population Balance Equation

Let n(v, t) denote the number density function of particles of volume v at time t. The evolution of n(v, t) due to binary aggregation and breakage is:

```
∂n(v,t)/∂t = A(v,t) + B(v,t)
```

where A and B are the aggregation and breakage operators respectively.

### 1.1 Aggregation operator

```
A(v,t) = (1/2) ∫₀ᵛ β(v′, v−v′) n(v′,t) n(v−v′,t) dv′
        − n(v,t) ∫₀^∞ β(v, v′) n(v′,t) dv′
```

The first term represents the birth of particles of volume v by aggregation of smaller particles. The second term accounts for their loss by aggregation with particles of any other volume. β(u,v) is the aggregation frequency function (kernel).

### 1.2 Breakage operator

```
B(v,t) = ∫ᵛ^∞ S(v′) b(v|v′) n(v′,t) dv′ − S(v) n(v,t)
```

where S(v) is the selection function (breakage rate) and b(v|v′) is the daughter size distribution. The quantity b(v|v′)dv is the expected number of fragments with volume in [v, v+dv] generated by breakage of a parent particle of volume v′. Volume conservation requires:

```
∫₀^v′ v b(v|v′) dv = v′
```

## 2. Sectional Discretisation

The particle volume domain is partitioned into N sections, each represented by a pivot volume xᵢ with:

```
0 < x₁ < x₂ < ⋯ < xₙ
```

The discrete unknown is the section-integrated number concentration:

```
Nᵢ(t) ≈ ∫_{v_{i−½}}^{v_{i+½}} n(v,t) dv
```

The k-th discrete moment is:

```
Mₖ(t) = Σᵢ xᵢᵏ Nᵢ(t)
```

with M₀ = total number concentration and M₁ = total particle volume concentration.

---

## 3. Fixed Pivot Method

In the Fixed Pivot Method of Kumar & Ramkrishna (1996), a newly formed particle of volume v* is assigned to the two neighbouring pivots xᵢ and xᵢ₊₁ that bracket it (xᵢ ≤ v* < xᵢ₊₁) with weights:

```
ηᵢ(v*)   = (xᵢ₊₁ − v*) / (xᵢ₊₁ − xᵢ)
ηᵢ₊₁(v*) = (v* − xᵢ)   / (xᵢ₊₁ − xᵢ)
```

These weights satisfy:

```
ηᵢ + ηᵢ₊₁ = 1                      (number conservation)
ηᵢ xᵢ + ηᵢ₊₁ xᵢ₊₁ = v*            (volume conservation)
```

Both particle number and particle volume are therefore preserved simultaneously during the allocation step.

---

## 4. Discrete Aggregation Operator

The aggregation contribution to the evolution of Nᵢ is:

```
dNᵢ/dt |_agg = Σⱼ Σₖ≥ⱼ (1 − δⱼₖ/2) βⱼₖ Nⱼ Nₖ ηᵢ(xⱼ + xₖ)
               − Nᵢ Σₖ βᵢₖ Nₖ
```

where βⱼₖ = β(xⱼ, xₖ) and δⱼₖ is the Kronecker delta. The first term (birth) is evaluated over j ≤ k to exploit kernel symmetry (βⱼₖ = βₖⱼ), giving M = N(N+1)/2 unique collision pairs. The factor (1 − δⱼₖ/2) accounts for self-collisions. The second term represents aggregation death.

### Supported aggregation kernels

| Kernel | Expression |
|---|---|
| Constant | β(u,v) = β₀ |
| Sum | β(u,v) = β₀(u+v) |
| Product | β(u,v) = β₀ uv |
| Brownian continuum | β(u,v) = β_BC (u^(1/3)/v^(1/3) + v^(1/3)/u^(1/3) + 2) |
| Brownian free-molecular | β(u,v) = β_BFM (u^(1/3)+v^(1/3))² sqrt(1/u + 1/v) |
| Shear | β(u,v) = β_Sh (u^(1/3) + v^(1/3))³ |
| Brownian continuum + shear | β(u,v) = β_BC(u,v) + β_Sh(u,v) |
| Brownian free-molecular + shear | β(u,v) = β_BFM(u,v) + β_Sh(u,v) |

The Brownian continuum kernel models perikinetic aggregation due to thermal motion. The Brownian free-molecular prefactor is supplied externally. The shear kernel models orthokinetic aggregation driven by velocity gradients.

---

## 5. Discrete Breakage Operator

The breakage contribution is:

```
dNᵢ/dt |_br = −Sᵢ Nᵢ + Σⱼ Sⱼ Nⱼ ∫₀^xⱼ b(v|xⱼ) ηᵢ(v) dv
```

where Sᵢ = S(xᵢ). The first term is the death contribution (local, no atomics needed). The second term redistributes daughter fragments from all parent sections j onto pivot i using the fixed-pivot weights ηᵢ.

Continuous daughter distributions are integrated by Gauss–Legendre quadrature with nq points per parent section:

```
∫₀^xⱼ b(v|xⱼ) ηᵢ(v) dv ≈ Σ_q bw_q ηᵢ(xⱼ t_q)
```

where t_q ∈ (0,1) are the normalised quadrature abscissae and bw_q = b(xⱼ t_q | xⱼ) · w_q · xⱼ are the pre-multiplied weights (j-independent for all supported daughter distributions on log-spaced grids).

### Supported selection functions

| Name | Expression |
|---|---|
| Constant | S(v) = S₀ |
| Linear | S(v) = S₀ v/v_ref |
| Power-law | S(v) = S₀ (v/v_ref)^α |
| Threshold | S(v) = S₀ if v > v_min, else 0 |

### Supported daughter distributions

| Name | Expression | n_quad |
|---|---|---|
| Uniform | b(v\|v′) = 2/v′ | Gauss-Legendre (user-chosen) |
| Symmetric binary | b(v\|v′) = 2δ(v − v′/2) | 1 (t_q=0.5, bw_q=2) |
| Power-law | b(v\|v′) = C(v′) v^q | 2-subinterval GL |
| Erosion | b(v\|v′) = δ(v−εv′) + δ(v−(1−ε)v′) | 2 |

All daughter distributions satisfy the first-moment conservation constraint, guaranteeing conservation of particle volume.

---

## 6. Semi-Discrete System and Time Integration

Combining aggregation and breakage, the semi-discrete PBE is:

```
dN/dt = R(N) = R_agg(N) + R_br(N)
```

where N = [N₁, …, Nₙ]ᵀ and R denotes the total source term vector. The library computes R(N) on the GPU. Time integration is the responsibility of the caller.

The worked examples use explicit Euler (for clarity) and RK4 (for accuracy):

```
Euler:  N^(n+1) = N^n + Δt R(N^n)

RK4:    k₁ = R(N^n)
        k₂ = R(N^n + Δt/2 k₁)
        k₃ = R(N^n + Δt/2 k₂)
        k₄ = R(N^n + Δt k₃)
        N^(n+1) = N^n + Δt/6 (k₁ + 2k₂ + 2k₃ + k₄)
```

RK4 is used in the paper and is recommended for production use. The library RHS function plugs directly into any standard ODE solver (CVODE, LSODA, etc.).

---

## 7. Conservation Properties

The fixed-pivot method preserves the following properties:

- **Volume conservation (M₁):** exact for aggregation events whose product volumes remain inside the computational domain, and for discrete daughter distributions. For continuous daughter distributions, conservation is achieved up to quadrature accuracy.
- **Boundary clipping:** when v* = xⱼ + xₖ falls outside [x₁, xₙ], the contribution is assigned to the nearest boundary bin. This introduces a small conservation error; the computational domain must be selected sufficiently wide to make clipping effects negligible.

---

## 8. Computational Complexity

| Operator | Complexity | Dominant cost |
|---|---|---|
| Aggregation | O(N²) | All pairwise collision pairs |
| Breakage death | O(N) | Local, one thread per bin |
| Breakage birth | O(N nq) | nq quadrature points per parent |

For nq ≪ N, breakage is negligible compared to aggregation at high resolution. Optimising the aggregation kernel is therefore the critical requirement for enabling ultra-high-resolution fixed-pivot simulations.
